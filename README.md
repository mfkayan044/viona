# VIONA - Handcrafted Beaded Bags E-commerce

A modern, elegant e-commerce platform for handcrafted beaded bags built with React, Vite, and Tailwind CSS.

## Features

- 🛍️ Modern e-commerce interface
- 🎨 Elegant design with Tailwind CSS
- 🔐 Admin panel for product and site management
- 🛒 Shopping cart functionality
- 📱 Fully responsive design
- ⚡ Fast performance with Vite

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
